# data/

Drop dataset exports here (from the app's Data tab → **Export dataset**) if
you want to version your recordings alongside the code, e.g.
`data/ksl_dataset_2026-09-19.json`.

Nothing here is read by the app automatically — exports are plain files you
manage yourself and re-import through the Data tab's **Import dataset**
button when needed. This folder is just a suggested home for them, and later
the natural drop point for any Phase 2 corpus files (see
`../docs/roadmap.md`).
